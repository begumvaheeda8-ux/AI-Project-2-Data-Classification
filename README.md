# AI Project 2 – Data Classification Using AI

## Project Overview
This project is part of the DecodeLabs Artificial Intelligence Industrial Training Program, Batch 2026.

The objective is to build a basic machine learning classification model using the Iris flower dataset.

## Technologies Used
- Python
- Jupyter Notebook
- Pandas
- Scikit-learn
- K-Nearest Neighbors (KNN)
- Matplotlib and Seaborn (if used in the notebook)

## Dataset
The Iris dataset contains flower measurements used to classify Iris flower species.

## Key Features
- Loads and explores the Iris dataset.
- Splits data into training and testing sets.
- Trains a KNN classification model.
- Evaluates model performance using accuracy and a classification report.
- Displays a confusion matrix (if included in the notebook).

## How to Run
1. Download the Jupyter Notebook.
2. Open it in Jupyter Notebook.
3. Run the code cells in order.
4. Review the model predictions and evaluation results.

## Project Objective
To understand basic machine learning, data classification, model training, and evaluation.
